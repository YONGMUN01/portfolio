프로젝트 개요

웹 애플리케이션 보안 취약점 분석 역량을 검증하기 위해 OWASP Top 10(2021) 을 기준으로 실제 공격 시나리오 기반 모의 해킹을 수행한 결과 보고서입니다.

진행 과정

  • OWASP Top 10 기반 취약점 분석 및 공격 시나리오 설계
  • Burp Suite를 활용한 요청 변조 및 인증 우회 검증
  • ExifTool을 활용한 Polyglot 파일을 제작 및 파일 업로드 검증 우회
  • 발견 취약점에 대한 보안 대책 정리 및 보고서 작성

공격 시나리오 검증 및 위험 분석

본 모의해킹에서는 PortSwigger 환경에서 제공되는 웹 기능을 기준으로 공격 가능 지점을 식별하고, 해당 지점이 실제 공격으로 이어질 수 있는지를 시나리오 기반으로 검증하였습니다.

검증 과정에서 입력값 처리 방식, 접근 제어 구조, 파일 업로드 검증 로직 등을 중심으로 분석한 결과, 일부 기능은 비교적 단순한 조작만으로도 취약점 악용이 가능한 구조임을 확인할 수 있었습니다.

결과 및 성과

  • OWASP TOP 10(2021) 기준 총 13건의 웹 취약점 식별
    (Critical 2건, High 8건, Medium 3건)
  • 각 취약점에 대해 단순 존재 여부 확인이 아닌, 실제 공격 시나리오를 구성하여 악용 가능성 검증 수행
  • CVSS v3.1 기준으로 취약점 위험도 산정 및 서비스 영향도(기밀성·무결성·가용성) 평가
  • 발견된 취약점에 대해 원인 분석을 수행하고, 적용 가능한 보안 권고안 도출

회고

PortSwigger Web Security Academy 환경을 대상으로 모의해킹을 수행하며, 웹 애플리케이션에서 발생할 수 있는 다양한 취약점을 공격 시나리오 기반으로 확인할 수 있었습니다.

특히 입력값 처리, 접근 제어, 파일 업로드 과정에서의 검증 로직이 공격자 관점에서 어떻게 악용될 수 있는지를 직접 확인하며, 단일 취약점이 추가적인 공격으로 확장될 수 있음을 이해할 수 있었습니다.
